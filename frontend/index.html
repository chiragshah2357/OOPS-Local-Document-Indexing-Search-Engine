    Indexing the sample files

    From a folder to a ranked list

    Four steps, each one a plain Java collection. The samples follow one sentence through all of them.

    1. Read

      Walks the folder and loads every .txt file into a string.

      threads-and-synchronization.txt

      A thread is the smallest unit of execution in Java.

    2. Split

      Lowercases the text, breaks it into words and drops filler like "the" and "is".

      a thread is the smallest unit of execution in java

    3. Index

      Records which files contain each word, and how many times it appears in each.

      thread
      threads-and-synchronization.txt2
      java
      file-io-basics.txt2
      java-collections.txt2
      threads-and-synchronization.txt1

    4. Rank

      Looks up each query word, combines the file sets, and sorts by total hits.

      java thread, any word

      • threads-and-synchronization.txt3
      • file-io-basics.txt2
      • java-collections.txt2
      • exception-handling.txt1

    The Java behind it

    Each concept from the brief has one job in the engine.

    HashMap

    The inverted index. Each word maps to the files containing it, with a count per file.

    Map<String, Map<Document, Integer>> index

    HashSet

    Holds the stop words, and gives match-all and match-any through intersection and union.

    PriorityQueue

    Keeps the best-scoring files on top, ordered by a Comparator.

    File I/O and Strings

    Walks the folder, reads each file and cuts the text into lowercase words.

    Collections

    A bounded Deque keeps the last ten searches, newest first.
